# deep-rl-course

Course repository for Deep Reinforcement Learning: lectures, exercises, and notebooks. This repository contains materials and code used in the course.

Structure
- notebooks/: Jupyter notebooks for experiments and demonstrations
- src/: source code for agents, environments, and utilities
- data/: datasets or saved environments (not tracked in repo)
- exercises/: exercise prompts and starter code

Getting started
1. Create a Python virtual environment: `python -m venv .venv`
2. Activate it: `source .venv/bin/activate` (macOS/Linux) or `.\.venv\Scripts\activate` (Windows)
3. Install dependencies: `pip install -r requirements.txt` (if present)
